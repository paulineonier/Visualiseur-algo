# Visualiseur d'Algorithmes de Tri

Un visualiseur interactif et léger développé en Vanilla JavaScript pour comprendre le fonctionnement des algorithmes de tri classiques étape par étape.

DÉMO EN LIGNE : https://<paulineonier>.github.io/<visualiseur_algo>/

---

## Fonctionnalités

- Visualisation dynamique : rendu visuel en temps réel via des barres de hauteur variable.
- Code couleur intuitif :
  - Jaune : éléments en cours de comparaison.
  - Rouge : éléments en cours d'échange (swap).
  - Vert : éléments triés et validés.
- Contrôle de vitesse : curseur permettant d'accélérer ou de ralentir l'exécution.
- Gestion d'état : verrouillage des commandes pendant le processus de tri.

---

## Algorithmes implémentés

1. Tri à bulles (Bubble Sort) — Complexité : O(n²)
2. Tri par sélection (Selection Sort) — Complexité : O(n²)

---

## Stack technique

- HTML5 / CSS3 (Flexbox, variables CSS)
- JavaScript ES6+ (Async/Await, Promises, manipulation du DOM)
- GitHub Actions pour le déploiement continu sur GitHub Pages

## Installation et lancement local

Aucun framework ni outil de build n'est requis.

1. Cloner le projet :
   git clone https://github.com/paulineonier/Visualiseur-algo.git

2. Lancer l'application :
   Ouvre simplement le fichier index.html dans ton navigateur, ou utilise l'extension Live Server sur VS Code.
